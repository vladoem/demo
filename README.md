### README

# Demo Repository

**desc**
This repository hosts a simple static site and sample scripts in Python and Node.js.

## Sample Code

### Python
`python_example.py` prints a friendly greeting.

```bash
python python_example.py
```

### Node.js
`node_example.js` outputs the same greeting using JavaScript.

```bash
node node_example.js
```

## Other Files
- `index.html` – basic HTML page
- `index.md` – Markdown reference sheet
- `repository.vladoem-1.0.10.zip` – example addon package
